# AI实践

记录 AI 应用开发相关实践，包括 Agent、RAG、MCP、Prompt 和 Automation 等核心方向。

- [Agent](/ai/agent/)：智能体架构、工具调用与工作流编排
- [RAG](/ai/rag/)：知识库、检索、重排、生成与评估
- [MCP](/ai/mcp/)：模型上下文协议与工具接入
- [Prompt](/ai/prompt/)：提示词设计、结构化输出与效果评估
- [Automation](/ai/automation/)：AI 工作流、工具连接与企业流程自动化
