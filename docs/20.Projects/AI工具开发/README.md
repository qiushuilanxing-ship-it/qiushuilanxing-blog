# AI 工具开发

这一部分记录面向日常内容生产的轻量 AI 工具实践。重点不在于堆叠功能，而是把高频、重复、规则清楚的工作变成更易使用的工具或流程。

## 已整理工具

### 豆包图片或视频去水印插件

用于处理**自有或已获得授权**的图片、视频素材，减少手工处理素材的重复步骤。

- [查看飞书使用教程](https://lcnu9zjo6wvs.feishu.cn/wiki/Www9wo7lUiE8qTkaqnTcgSG2nad)

> 仅应处理拥有版权或已获得合法授权的素材。第三方平台能力会随版本与服务状态变化，使用前以实际页面为准。

### 扣子反推视频提示词插件

通过对标视频梳理选题、结构、节奏和文案思路，再结合自己的产品资料生成可修改的提示词草稿。它用于获取创作方法，不应用于直接复制原作品。

- [查看飞书使用教程](https://lcnu9zjo6wvs.feishu.cn/wiki/K9S3wnzhYiCHAMkICsQcxOc9n3K?from=from_copylink)
- [查看成功案例展示](https://lcnu9zjo6wvs.feishu.cn/wiki/VcZtwDr33iDbD6k4XhocbW8snFg?from=from_copylink)

## 一个更稳定的使用流程

```text
明确内容目标与目标用户
        ↓
准备自有产品资料与可参考案例
        ↓
反推结构、生成提示词草稿
        ↓
核验产品事实、素材授权与品牌表达
        ↓
生成内容或进入后续视频制作
        ↓
沉淀有效模板与复盘结果
```

产品参数、价格、活动与效果承诺必须来自已确认资料。案例只用于学习表达结构和创作节奏；当信息缺失时，应先补充信息，而不是让模型猜测。

## 从单点工具到自动化能力

工具可以解决单一操作，工作流则把“反推提示词 → 补全资料 → 内容生成 → 人工审核 → 视频制作”连接成可重复使用的生产路径。相关实践见：
