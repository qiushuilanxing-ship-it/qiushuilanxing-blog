# 视频质检系统

![视频质检系统界面](/img/video-audit/audit-dashboard.png)

MileVideoAudit 是一套面向电商短视频的半自动内容质检系统。它将账号内的视频采集、画面与音频证据提取、产品资料核验、AI 审核和 Excel 交付串成一条可追溯的流水线。

## 解决什么问题

家电品牌在短视频平台持续发布带货与种草内容。人工逐条核验时，容易遇到处理成本高、判断标准不一致、问题缺少可回查证据等问题。

系统重点检查：

- 产品型号、参数、功能和卖点是否与已确认的官方资料一致。
- 是否存在跨型号套用、虚假或夸大表述。
- 画面文字、字幕和品牌信息是否存在明显错误。
- AI 生成内容是否按既定规范完成声明。

它不只是给视频打一个“合格/不合格”标签，而是让每项判断都能回到画面帧、音频片段和知识依据。

## 从视频到报告的完整链路

```text
账号范围与日期
        ↓
分页采集、下载、去重与完整性校验
        ↓
抽帧 + ASR 并行生成结构化证据
        ↓
逐帧视觉观察与知识库检索
        ↓
AI 审核 + 画面文字复核 + AI 声明检查
        ↓
确定性 Guard 校验
        ↓
Excel 报告、人工复核与问题闭环
```

采集、证据、校验和报表等确定性步骤由程序完成；语义理解与复杂画面判断交给模型；最终通过 Guard 把模型结论约束回可验证的证据和规则。

## 核心能力

| 环节 | 能力 | 目标 |
| --- | --- | --- |
| 内容采集 | 按账号与日期分页扫描、下载、去重、断点恢复 | 确保审查范围完整 |
| 证据提取 | 视频抽帧与 ASR 并行，统一为结构化 Evidence | 为每个判断保留来源 |
| 语义审核 | 对照质检规范与产品资料，输出 `PASS`、`CONFLICT` 或 `NEED_CONFIRM` | 区分可放行、冲突与待人工确认 |
| 画面复核 | 检查画面中的品牌、型号、参数、字幕和卖点 | 以实际画面为准 |
| AI 声明检查 | 识别平台声明或画面中的 AI 标注 | 补齐内容合规检查 |
| 交付与复盘 | 多 Sheet Excel 报告、统计与知识库缺口 | 让人工聚焦疑难问题 |

## 为什么要有确定性 Guard

AI 可以帮助理解视频表达，但不能自行伪造证据、跳过知识来源或把不确定信息写进交付报告。因此，最终结果必须通过结构、绑定、错配和时间点等机械校验。任何一项不满足，结果不会作为正式问题进入报告。

## 关键工程原则

### 官方资料优先，缺资料先确认

产品参数与功能结论只以已确认资料为依据。缺少资料时，系统识别为知识缺口，而不是凭常识补全；后续由人工补充资料并确认后再进入正式审核范围。

### 逐帧证据优先于泛化判断

涉及文字、型号、参数或字幕的判断必须能定位到具体画面。无法确认时，输出 `NEED_CONFIRM`，而不是把模糊识别包装成确定结论。

### 质量、速度与可追溯并重

在阶段性验证中，单视频处理耗时约为 77 秒（P50 约 80 秒）；一次全链路账号审查覆盖了 124 条视频。该记录用于说明工程验证能力，并不构成所有输入条件下的处理时效承诺。

## 技术组成

- **采集与编排**：Python、HTTP 客户端、分页与去重逻辑。
- **媒体证据**：FFmpeg 抽帧、faster-whisper 语音识别、逐帧视觉分析。
- **模型审核**：LLM 语义判断与多模态视觉复核。
- **知识依据**：质检规范与官方产品资料库。
- **质量控制与交付**：JSON Schema、确定性 Guard、openpyxl 报表。
