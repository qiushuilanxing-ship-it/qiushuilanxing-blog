# LiveInspector - AI直播智能巡检平台


  ![效果展示页面](/img/zhiboxunjian/effect.png)


## 项目简介

LiveInspector 是一套面向企业直播场景的智能巡检系统，通过本地客户端采集直播运行状态，结合 AI 视觉检测与服务端管理平台，实现对多直播间、多设备的自动化监控与异常告警。

系统用于解决企业直播过程中人工巡查成本高、异常发现不及时、直播质量难量化等问题。

## 核心功能

### 1. 直播实时状态监控

通过客户端持续采集直播状态，实现：

- 直播画面采集
- 视频流状态检测
- 音频状态检测
- 主播在线状态分析
- 黑屏、冻结等异常识别
- 客户端在线状态监测

### 2. AI视觉智能巡检

基于计算机视觉模型，对直播画面进行自动分析：

- 主播是否在场
- 是否出现黑屏
- 是否长时间静帧
- 画面稳定性检测
- 异常画面识别

减少人工盯盘成本，提高直播质量保障能力。

### 3. 自动异常告警

系统支持异常事件自动检测与通知：

- 直播中断
- 客户端离线
- 音频异常
- 视频异常
- 黑屏异常

异常触发后自动推送飞书机器人消息，帮助运营人员快速处理。

### 4. 多直播间管理

管理端支持：

- 多直播间绑定管理
- 设备管理
- 负责人配置
- 巡检状态查看
- 历史告警查询
- 数据统计分析

实现企业级直播运营管理。

### 5. 实时直播观看

提供网页端直播查看能力：

- 自动解析直播流
- HLS 转换播放
- 多用户共享观看
- Viewer 会话管理
- 自动清理无效播放任务

支持运营人员在后台快速查看直播状态。

## 项目价值

LiveInspector v0.4 是一套面向主播电脑的直播运行巡检系统：它自动检查本地直播画面、音频和主播在岗状态，将异常形成可追踪事件，并同步到服务端与通知渠道，减少运营人员持续盯盘的压力。
1. 主要解决的问题
直播过程中常见的“无人出镜、静音、黑屏、预览卡住、巡检电脑断网”等问题，若靠人工发现，往往滞后且难以追溯。项目聚焦主播端本地状态，提供发现、告警、恢复确认、留痕和集中查询的闭环。
它不等同于观众端体验质检：当前实现不能证明观众侧一定不卡顿或画质正常。
2. 已实现的核心功能
  - Windows 客户端：可选直播伴侣等窗口、鼠标框选巡检区域，并显示实时画面与检测结果。
  - 两类画面来源：本地窗口采集，以及抖音直播流采集；后者可用“影子模式”只验证采集与识别，不触发正式告警或上报。
  - 本地检测：黑屏、本地预览冻结、无人、静音、音频输入中断，以及可选的手机检测。
  - 告警规则：支持持续时长、计数、防抖、冷却、异常触发与恢复的完整生命周期，而非逐帧重复报警。
  - 本地提醒与证据：异常时可在主播电脑上显示置顶提醒，并保存事件与必要截图。
  - 服务端闭环：设备注册与心跳、事件/截图接收、本地 SQLite 离线队列与恢复补传、服务端持久化、通知投递。
  - 直播状态与管理能力：服务端可探测直播间状态，以“已确认开播”控制业务告警；同时提供直播间、设备、告警、概览和统计查询能力，供管理端接入。
  - 网络韧性：实现了客户端断网本地提示、服务端离线看门狗、恢复稳定期，以及对历史技术事件的隔离处理，避免恢复后误报为直播中断。
3. 整体工作流程
配置直播间与巡检区域 → 客户端采集画面/音频 → AI 与规则引擎判断异常 → 本地提醒及事件留痕 → 离线队列或实时上报 → 服务端关联直播间、通知责任人、沉淀查询与统计
其中，未确认开播或平台状态不确定时，系统倾向于只预览、不累计业务异常，避免把“未开播”误判成“主播离岗”。
4. 主要技术
  - Windows + Python 客户端，带图形化配置和系统托盘能力
  - OpenCV、NumPy、MSS、Pillow：画面采集与基础视觉分析
  - Ultralytics YOLO：人员、手机等目标识别
  - SoundDevice：本地音频监测
  - FFmpeg：直播流音视频读取
  - FastAPI、SQLAlchemy、SQLite：服务端、事件存储与查询
  - HTTP 客户端、加密组件：设备通信、离线补传和敏感通知配置保护
5. 值得借鉴的设计
  - 统一采集边界：本地窗口与直播流最终进入同一套分析、规则和上报链路，避免两套检测逻辑分叉。
  - “未知不等于掉播”：平台探测失败、风控或接口变化时会进入不确定状态，而不是直接判定直播中断。
  - 告警按事件实例管理：异常、触发、恢复关联为同一次事件，便于抑制重复通知、计算持续时长和后续分析。
  - 本地优先、云端闭环：主播端可快速提示，网络恢复后依靠本地持久队列补传，不因短暂网络波动丢失记录。
  - 安全边界清晰：通知凭据不放在客户端日志或普通配置中；直播间链接限制平台域名并拒绝内网地址。
